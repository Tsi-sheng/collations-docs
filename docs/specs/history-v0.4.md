## 最小接口契约（拟定，不是现有签名）

采用平台无关的 core 规划/校验 + 原生适配执行，具体命名在实现PR保持与本表语义一致，不引入网络或数据库直连。

| 能力 | 输入 | 输出/保证 |
|---|---|---|
| prepareCommit | 已校验Manifest原文及代次、受管来源原始字节/身份/路径、声明的作品路径、预期HEAD、用户说明 | 候选Revision、去重对象清单、完整来源指纹及诊断；不写磁盘 |
| publishCommit | 候选及预期HEAD/Manifest/来源指纹 | 原生持锁初验、写准备事务/对象/候选、发布前再次重枚举和重验；检测到竞态返回冲突。HEAD原子替换是发布点，快照边界见下文 |
| listRevisions/readRevision | 受限工作区、当前可验证HEAD或显式Revision ID | 校验后的已发布历史；拒绝越界/未知版本/损坏及循环父链；不把孤立候选默认当已发布版本 |
| readObject/verifyHistory | 对象hash或指定Revision | 原始字节/逐项完整性诊断；缺失/损坏不静默重建 |
| compareRevisions | 两Revision、可选Document ID | 增删/移动/内容变化；文本比较辅助显示，二进制报告hash/size；原字节不被规范化 |
| planRestore | 目标Revision/Document ID、当前身份/原始指纹、确认的附件范围 | 只读差异与预条件、影响范围和需用户确认项；无文件写入 |
| applyRestore（B阶段） | 已确认方案、会话保存门禁、最新预条件 | 先恢复前Revision，再日志化字节替换与索引更新；失败保留可恢复证据 |

平台适配只接受已打开工作区内经校验对象键/相对路径，不暴露任意路径写入。原生端不能信任前端传来的任意映射或hash，必须重算和复核身份。所有过程使用同一工作区串行锁；锁失败返回busy，不终止未知进程。

## HistoryStore v1 最小记录

Revision 清单拟含独立 formatVersion=1、revision UUID、parent UUID/null及parentManifestSha256/null、创建时间与用户说明、来源声明、identitySnapshot对象hash、entries和missingDocumentIds。

- entries记录kind(document/asset/composition)、保留大小写的相对path、SHA-256、size；只有document必须带Document ID。唯一Document ID及大小写折叠后的路径不冲突；条目按路径UTF-16序固定排序，与现有JS适配约定一致。
- identitySnapshot对象保存提交时Manifest v3原始字节，仅证据/校验用途，恢复不直接覆盖当前清单。缺失登记保留ID/path于快照，missingDocumentIds明确未有正文对象；有未解决身份冲突时拒绝发布首版历史。
- head.json单独formatVersion=1、generation、revision和清单原始字节sha256。Revision ID不是清单hash，也不是Manifest generation。非首清单的parentManifestSha256是父清单原始字节SHA-256；从受信HEAD的摘要沿父链逐一校验，缺失或不匹配拒绝旧版本读取/比较/冻结汇编，不能只验证JSON结构和内容对象。根清单parent及其摘要均为null；不接受只带UUID的非首清单。首次旧HEAD=null必须由准备事务记录初始化依据，不能以指针缺失推断历史为空。
- 对象必须小写64位SHA-256，ID为UUID，路径遵循原生Windows边界和core逻辑校验；不读取symlink/junction/硬链接。未知格式拒绝写入，保留原文件。对象按原始字节哈希，BOM/混合换行不规范化。
- 新提交parent为发布前HEAD，顺序形成线性显式历史，首版不提供分支/merge/GC。无变化仍可由明确提交产生新Revision，共享已有对象；自动保存不调用该能力。
- A阶段新增格式样例和验证测试，当前没有历史格式迁移要执行。已有documents.json v1/v2到v3继续用既有身份迁移，不能通过历史初始化偷偷升级或重置身份。

## 并发、保存与恢复边界

显式提交和汇编的来源是磁盘字节，不静默收取编辑缓冲。UI先展示未保存/冲突状态：用户选择保存后提交，或取消操作；B阶段恢复前必须妥善保存或保留持久草稿，未解决外部冲突禁止恢复。在写对象前初验、写完候选后最终重枚举/重读来源并核对字节、Manifest和HEAD，任一已检测变化中止发布并保留候选供诊断。外部程序不受应用锁约束，有限次数读取不可能保证整个集合在同一时点一致；版本定义为经过两轮逐项核验的采集集合，不是OS原子快照。最终校验后的外部写入属于之后的工作状态，不能承诺检测所有这种写入。若业务将来要求原子时点快照，须另评审原生快照/外部写入排他机制，不作为A1隐含能力。

恢复先用当前路径定位Document ID，但首轮自动恢复只允许与历史路径完全相同。路径移动/改名返回PATH_RECONCILIATION_REQUIRED，保留计划不执行；独立协调后重新生成计划。对相对文档链接校验目标当前身份与历史对应关系，对附件计算目标路径并验证边界/占用；若解析到不同文档、未知目标或改变的相对位置，返回引用诊断，不静默改写正文。目标正文原始字节来自旧对象。预览列出将替换/创建的附件和所有受影响引用；恢复历史路径、缺失文档、身份歧义不自动处理。新目录只在工作区范围内按需创建；既有目标必须校验hash，排他创建失败保留现场。

历史发布重启判定：先验证准备记录及旧/新HEAD摘要。可信旧HEAD仍在则候选未发布；可信新HEAD及其完整对象链有效则已发布（回执未送达也不能再假称失败）；未知指针或证据冲突转只读。首次旧HEAD=null且准备记录唯一可信时可判定未完成首次提交并保留对象重试；孤立残留没有这种依据则不能初始化。事务记录不作为旧版本清单唯一校验来源，父摘要链必须完整。

恢复前显式Revision完全发布后才写目标；事务记录包含前/后hash、计划、已完成步骤、恢复前Revision及Manifest预期代次。重启仅在每个路径匹配已知前态或后态且事务证据完整时恢复；遇第三方未知字节停止并报告，不能用回滚覆盖新编辑。索引失败标记需重建，不撤销已经确认的正文或身份。SQLite删除不影响对象、版本、草稿和事务。

版本提交事务与恢复事务分别处理，均不是SQLite事务；详细原生崩溃边界要在B阶段实际测试后才能标通过。旧有os error 5另行跟进，不据此跳过权限错误验收。

## 汇编对接边界

沿用现有version:1 YAML，chapters有序，document引用稳定ID，block可选，顶层revision可选。首轮不新增逐章revision语法。未固定作品使用当前磁盘，固定作品所有正文、路径和附件从同一Revision读取，不能回退读取当前笔记补缺。

未知锚点、缺失对象/文档/资源、歧义目标明确诊断。编译器只读输入，输出Markdown、附件、来源映射；标题锚点按章节唯一化，输出目录成功后才发布。版本范围不含的依赖必须报错，不称导出完整。实现与验收属于C阶段，本批无汇编代码或假UI入口。

## 实施顺序及验收矩阵

| 阶段 | 交付 | 必须验证 |
|---|---|---|
| A1 | 版本化样例、schema校验、core纯函数与内存适配 | UUID/hash分离、重复内容双身份、BOM/混合换行保真、非法路径/重复ID、未知版本拒绝 |
| A2 | 对象/清单存储、HEAD发布及完整性 | 排他对象写入、损坏对象拒绝、两窗口HEAD竞争仅一成功、源集合变化中止、准备/对象/清单/最终复核/HEAD各边界中断，首次空历史中断恢复，最终复核后编辑按采集语义报告 |
| A3 | 列举/读取/比较 | 同ID移动与内容变化分别报告；已发布父链验证；旧清单被改为指向另一合法对象仍须因父摘要失配拒绝，缺失/损坏/孤立候选可解释；SQLite删除历史仍可读 |
| B | 安全恢复原生适配与独立历史视图 | 当前内容先保全、附件二进制、替换竞争备份、未知外部编辑不覆盖、重启恢复、身份历史不倒退、索引失败可重建；历史a/n.md引用img/p.png而当前b/n.md时阻止，文档链接换身份亦阻止 |
| C | Markdown汇编器与作品视图 | 两讲义复用证明，更新草稿/重建冻结版，附件和锚点重写，搬移导出目录离线阅读，来源映射准确 |

A先core纯测和临时真实文件集成，B增加Windows故障注入/真实进程退出，C增加中文数学样例端到端。测试用公开合成资料，不引入私人笔记。所有结果绑定提交/脚本/exe；本表是将来验收要求，无一项因写入本文而变为通过。

## 工作包与分工

main负责协议、core及原生适配授权、任务板和串行集成；ui只在接口审查后设计独立历史/比较/确认/作品视图，遵守Figma优先；regression准备固定提交的合成样例及证据；review只读审查身份、发布和恢复边界。此轮不调度UI画布、不占回归端口、不增加对话。

当前仅文档协议审查。审查关口之后依次A1/A2/A3；第一份提交/恢复测试完成再估算日历工期。高级布局、只读插件、Capture/AI、同步及Mac Bridge不并入。每包独立待审PR，不自动合并。
