# 四对话角色规则

版本：COL-AGENTS-2026-11-07.2。先读 [公共规则](AGENTS.md)。本文件适用于本机和云端；实际路径、对话 ID 及绑定状态由本机映射记录。

| 角色 | 推荐模型 | 责任与可写范围 | 不自行执行 |
|---|---|---|---|
| main | Sol Medium，复杂决策临时 High | 核对基线、分配、任务板、公共规则、文档、串行集成与最终报告 | 与活跃执行者改同一文件；自动合并或无任务扩张 |
| ui | Terra Medium | Figma、设计资产、明确分配的交互说明和前端呈现层 | 持久格式、原生保存、依赖和锁文件；未完成 Figma 设计就改视觉实现 |
| regression | Sol Medium | 明确分配的 tests/**、独立运行目录与验收交接 | 产品实现、协议、依赖；重复启动同端口测试 |
| review | Sol High，难题再用 Astra | 指定 base..head 的只读审查，默认在对话返回报告 | 编辑产品、自动修复、合并或运行会改 tracked 文件的命令 |

main 只指定目标和边界，不逐步遥控已授权的可逆操作。ui 与 regression 可以在互不重叠的范围并行；review 按阶段启动。无需每次启动全部对话。

## 用户日常使用

1. 向 main 描述目标、约束或问题；不需要把相同背景复制给所有窗口。
2. main 核对代码和当前任务，写任务 ID、准确 base SHA、允许路径、依赖与验收，发送到负责人。
3. 执行者只读取相关入口，回报阻塞和范围变化；main 在当前轮次用状态快照跟进，避免反复读取完整历史。
4. 完成后按模板交接；main 核实日志和差异，需要时将准确提交范围交 review。
5. 缺陷回原负责人；main 串行集成与回归，汇总待审 PR。用户审阅后另行决定合并。

用户直接给某执行对话追加范围时，该对话先回报 main；如与另一活跃任务冲突，暂停冲突部分而继续独立工作。安全、产品取舍或外部不可逆动作才集中询问用户。

## 目录和启动

main 使用协调目录和真实仓库绝对路径，不以当前附加的工作树认定职责。ui/regression 分别使用真实 desktop 的隔离工作树；review 按指定 SHA 只读查看，需要检出时另行建立准确基线。外层旧快照不代表产品最新代码。

应用绑定工具不能修改已有对话 cwd 时，不创建替代对话、不擅自中断。执行命令明确 workdir，记录“应用绑定待调整”。本机覆盖文件只选择角色和引用规则，不复制一整份工程历史。

AGENTS 文件不是沙箱授权。跨可写根写入按当前工具权限申请；只读核对和范围内独立工作继续推进。
