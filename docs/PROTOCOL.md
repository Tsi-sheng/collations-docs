# 工作区协议草案 v1

> 2026-11-13审查：下述版本/汇编是既有目标，不是现有实现。新增[HistoryStore待审ADR](adr/0008-history-store.md)和[接口/实现方案](specs/history-v0.4.md)明确拟定边界，不修改Manifest v3。

**身份与链接。** 工作区的 .collations/documents.json 登记版本号、Document ID 和当前相对路径。ID 首次登记时生成 UUID，重命名时更新路径。内容相同仍分配独立 ID。外部移动仅在可靠且唯一的平台文件身份匹配、旧路径消失且全局映射无矛盾时自动关联，有歧义时请求用户选择。创建块引用时在块前写入 HTML 锚点，目标块范围为紧随的 Markdown 块；标题则包含其下至下一同级或更高级标题之前的内容。

默认写入相对 Markdown 链接，可带标题或显式锚点。解析 Markdown 语法树，忽略代码中的链接样例。Obsidian 双括号链接支持别名和块标记；同名目标列出候选。诊断包含源文档、文本位置、目标及原因。路径修复先显示变更再写盘。

**版本与恢复。** 对原始字节计算 SHA-256，小写十六进制作为对象键；首轮不实现可选 MD5 兼容字段。提交先写入并校验文档、附件及作品清单对象，再原子发布含 revision、parent 和条目列表的清单。条目保存路径、对象键和文档身份。自动保存更新工作文件。恢复时先提交当前受管来源快照（不含未纳管文件，不能冒充全库备份），再校验目标对象、记录恢复日志、替换文件和重建派生索引。中断后根据日志继续或回到恢复前提交。

**汇编。** 独立 YAML 使用 version、title 和有序 chapters，每项以 document 指定稳定 ID，可加 block 选择范围。顶层 revision 缺省时读取当前工作区，填写时所有源文档、路径和附件取自该快照。生成一个 Markdown 文件、资源目录及 JSON 来源映射。映射记录输出行区间、文档与块 ID、源对象哈希和已用版本。输出锚点按章节唯一化，改写交叉引用，按哈希复制附件。缺失引用先报告；构建成功后才发布整个输出目录。

Manifest v2 的兼容读取、恢复边界与持久化顺序见 [Windows 工作区身份和派生索引](adr/0002-windows-index.md)。
