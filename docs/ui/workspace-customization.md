## 目标与边界

日常界面优先写作：文件树、标签、紧凑工具栏、源码／预览切换、保存状态；右侧辅助默认收起。宽屏初始分栏，窄窗初始源码，主动选择受尊重。秩笺青绿色与蓝灰色体系、既有语义变量和可编辑组件须在画布恢复后核对；不复制第三方资产。布局由用户主动调整和记忆，不按频率自动改变。版本、汇编出版、文献与采集是独立任务视图的规划，未实现模块不进入默认界面或伪装成可用入口。

高级能力只在“编辑布局”中显露；日常锁定布局但分隔条可调整宽度。设计不直接并入 v0.3 前端 PR。本文是交互目标，不是对当前代码或持久架构的承诺。正文、草稿、身份和离线编辑、索引、出版遵守既有协议；本轮不改 Manifest v3、不定义持久 schema。持久协议若未来改变，须另附 ADR、格式版本、迁移样例和恢复测试。会话、窗口通信和保存接口须由 main 与 review 在实现前单独评审。

## 布局编辑与预设

提供三个可恢复的内置预设：「专注写作」为源码单栏、两侧关闭；「公式校对」为文件树、源码／预览等宽、辅助关闭，也是首次宽屏默认；「阅读引用」为预览、文件树、反链辅助。窄窗只做临时适配，不写回预设。用户可将当前布局另存为命名预设，并复制、重命名、删除自己的预设；内置项不可删除或直接覆盖，可复制后修改。名称为空或重复时在输入处解释并保持对话框打开；删除用户项须确认。删除正在使用的预设不改变当前布局。恢复内置预设与恢复当前布局的默认值均需明确目标并确认，不清除正文、草稿或身份。

进入编辑时以当前布局 A 为快照，所有布局变更和预设的新增、删除、改名均只进入草稿，显示手柄、停靠目标和拆分预览。选择已有预设 P 时，同样从当前 A 进入编辑，将 P 加载到布局草稿供预览；不立即覆盖 A。左右／上下拆分、移动标签组、停靠辅助面板、应用内浮层和拖为独立 Windows 窗口均可通过可见菜单及键盘完成；拖拽不是唯一途径。键盘可选择对象、目标与方向，确认提交，Esc 取消操作并返回发起控件；无效目标标明原因，丢失目标时保留原位置和焦点，不丢弃视图。切换至窗口外目标仅为设计契约，不假设底层已有支持。

「保存为预设」从布局草稿 B 建立待提交 P，界面标明「随应用保存」；预设删除、改名也待应用。应用成功才提交布局和预设变更并退出编辑；取消或 Esc 在无子操作时丢弃待提交 P 和其他预设草稿，回到 A，不产生永久变更。失败时保留草稿和已确认的旧状态，不提示成功；若无法确认提交结果，显示「待核对」、暂停重复提交并保留会话，核对结果后再决定后续操作。「恢复默认」仅替换布局草稿，应用后生效，取消可回到 A。预设仅描述布局，不包含全局工具栏、快捷键、正文、草稿或身份；应用不关闭当前文档，保留现有视图，仅重排承载容器。操作造成面板暂不可见时将焦点移至可见的对应标签或主编辑区，关闭菜单／对话框返回发起控件；不可见或已销毁时回退至当前组标签。重启恢复失败采用安全默认并提供恢复入口，不修改正文或重建 Manifest。这是交互事务要求，不是持久 schema 或现有原子提交能力的承诺。

## 文档、导航与辅助信息

单击文件打开临时标签；双击固定。单击另一文件只可替换本组未修改、无草稿恢复或冲突的临时标签；开始编辑、恢复草稿或出现冲突立即固定，未保存内容不得被替换。同组重复打开同一 Document ID 聚焦已有标签；「在旁边打开」显式建立另一视图，不改变文档身份。关闭非最后视图只关闭该视图；关闭最后视图时按保存、未保存、保存中、冲突／只读或恢复草稿等实际状态提供安全处理，不能静默丢弃：保存成功后关闭、取消返回，冲突先审阅或保留草稿，保存失败保持打开并说明。确需丢弃时须明确确认其影响，不将其作为默认动作。

后退／前进记录文档及标题、块或源码位置，以及返回所需的视图位置。例如历史为原证明位置 P0 → 定理 T0 → 引用中的证明位置 P1：后退一次到 T0，再一次到 P0；前进依次到 T0、P1，不另设专用返回动作。不可定位时说明目标失效，保留当前文档并提供最近可用位置，不假装精准恢复。主题、源码／预览／分栏、模块和布局切换保留会话、未保存正文、光标、选区、滚动和撤销能力。大纲标注「当前缓冲区」，随编辑更新；入链／出链标注「最近保存版本」，索引可能尚未更新时说明，空结果和加载失败分别表达。信息按可用文件和身份数据展示，不凭示例推断。

## 设置和状态归属

设置为独立页面，退出返回进入前位置；更改使用清楚的应用／取消与恢复入口。普通设置应用失败时明确显示未保存，保留编辑草稿，焦点移至错误摘要或首个无效项，允许修正、按公共规则重试或取消；取消恢复上次已应用值。五组：

| 组 | 内容与操作 |
|---|---|
| 外观与阅读 | 主题、字体、字号、行高、正文宽度、换行、动效；预览后可应用或取消。 |
| 编辑与打开方式 | 临时标签、默认源码／分栏／预览、辅助面板与导航偏好。 |
| 布局 | 内置与用户预设、命名管理、编辑布局、恢复布局。 |
| 工具栏 | 真实可执行命令的显隐、排序和溢出；始终保留可达的「更多命令」及恢复入口，键盘可重排。 |
| 快捷键 | 搜索命令、录入组合、显示冲突与涉及命令；应用前解决或取消，不静默覆盖；支持恢复单项与全部。 |

概念上分别保存应用偏好、工作区布局、各文档视图状态；本文不指定存储结构。临时窄窗适配不覆盖宽屏偏好，回到宽屏恢复原选择；用户明确更改的偏好另行保存。「恢复布局」与「恢复全部设置」分别确认范围，均不得清除正文、恢复草稿或文档身份。持久化失败须可见，不能宣称已保存。

## 独立窗口与恢复契约

同一工作区同一 Document ID 对应一个逻辑文档会话及一个保存通道；多个视图共享正文、修改／保存／冲突及只读状态和文档撤销历史，每个视图独立维护光标、选区和滚动。所有相关窗口一致显示冲突与只读保护，避免各窗口自动保存竞争。该共享机制尚未实现或验证，Figma 表达目标而非代码能力。

主窗口及独立窗口均标示工作区；关闭独立窗口可选择收回主窗口，若关闭最后视图则先走上述安全关闭流程。跨工作区拖动不自动移动文件或身份，拒绝或提示用明确的独立操作处理。显示器断开、分辨率变化、重启后将窗口恢复到可见区域；无法还原位置时提供收回主窗口。恢复失败回安全默认布局并保留文档及草稿；失败提示须可见且可重试，不能把位置恢复失败当正文恢复成功。
