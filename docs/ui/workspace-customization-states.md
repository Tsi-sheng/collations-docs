## 两条完整原型路径

1. **写作导航**：D01 在示例「证明」的 P0 编辑并保留未保存状态 → D04 单击「定理」到 T0 临时查看 → 双击固定 → D02 查看标明最近保存版本的反链 → D05 跳到引用证明位置 P1 → 后退一次到 T0，再一次到 P0 并恢复原光标、选区与滚动；前进依次到 T0、P1。加入 D06 空／失败及 D05 目标失效分支；不以原型代替真实数据或导航测试。
2. **工作区定制**：D01 → C04 进入布局编辑 → C05 拆分标签组 → A02 拖出独立窗口（提供菜单和键盘替代）→ C07 从当前草稿保存命名预设，显示「随应用保存」→ C04 应用 → C02 调整工具栏 → C03 录入并处理快捷键冲突 → C07 选择默认预设，载入草稿并应用 → C07 选择自定义预设，载入草稿并应用。工具栏和快捷键独立于布局预设。覆盖 C06 停靠失效、A04 断屏收回和取消路径；保持会话与正文。原型只是模拟，底层跨窗口共享未实现。
