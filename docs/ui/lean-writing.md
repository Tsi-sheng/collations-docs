## 页面与状态

| 状态 | 画板尺寸 | 构成 |
|---|---|---|
| 默认写作浅色 | 1440 × 900 | 文件树、标签、紧凑编辑工具栏、源码／预览近等宽分栏、底部保存状态。右侧辅助栏收起。 |
| 文档辅助 | 1440 × 900 | 从工具栏打开宽约 280 px 的辅助面板。大纲、反链、文档信息以选项切换，每次突出一项。 |
| 模块菜单 | 1440 × 900 | 左上角打开菜单，提供写作与知识关系入口。维护菜单由工作区名称进入。 |
| 默认写作深色 | 1440 × 900 | 与浅色保持同一结构，使用既有深色语义色。 |
| 窄窗源码 | 720 × 800 | 文件树为抽屉，默认源码，可切换预览。工具栏保留辅助面板入口。 |
| 窄窗辅助 | 720 × 800 | 以抽屉展示文档辅助，关闭后回到原编辑位置。 |

预览、分栏和辅助面板均应保留明确入口。宽屏初始分栏，窄窗初始源码。五区比例仅用于辅助面板展开状态，默认收起后的空间全部分配给写作区。

## 导航层次

左上角品牌按钮打开模块菜单。写作与知识关系使用独立任务视图。版本、汇编出版、文献和资料采集作为后续规划写在说明中，产品入口随实现进度开放。

工作区名称旁的菜单收纳打开目录、新建文档、新建文件夹、扫描、索引重建及备份。默认写作画板不常驻这些维护操作。

文档辅助包含「大纲」「反链」「信息」三项。大纲来自当前缓冲区，反链来自最近保存版本，信息以文件系统和身份清单为依据。各项的空状态与加载错误均单独表达。

## 组件和交互

沿用秩笺的青绿色、蓝灰背景、语义变量与可编辑图层。借鉴紧凑工作区与导航习惯，任何第三方代码、图标或主题资产在使用前逐项核对许可证。

页面示例使用中文数学笔记，标注为示例数据。示例关系和文件数量不作为产品能力证明。

原型覆盖以下行为。

1. 左上角打开模块菜单，进入知识关系，再返回写作。
2. 打开文档辅助，切换大纲／反链／信息，再关闭面板。
3. 工作区菜单打开后展示维护操作，关闭后恢复编辑焦点。
4. 宽屏默认分栏，窄窗文件抽屉、预览和辅助抽屉均可到达。
5. 冲突、恢复和链接修复在相关事件发生时提示进入独立审阅流程。

为上述切换标注必须保留的标签、草稿、光标、选区、滚动和撤销历史。Figma 仅表达期望交互，实现验证单独记录。

## 交付检查

默认、辅助、菜单、深色和窄窗状态均可编辑。检查文本裁切、布局溢出、正文宽度、主题对比、焦点与入口可达性。取得本次修订的总览截图及默认写作独立截图，保存至 assets，记录节点、带时区时间、文档基线及 SHA-256。

最终回复直接展示本次截图，附画板链接及尚未验证项。未取得新截图时，状态保持「截图验收未完成」，历史截图仅用于对照。
