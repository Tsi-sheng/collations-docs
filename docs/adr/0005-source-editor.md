# 0005 编辑会话与正文保存

索引的 body 是派生文本。编辑器按 Document ID 打开源文件，以其完整 UTF-8 字节 SHA-256 建立保存基线；BOM 和每行原有分隔符属于正文格式。仅预览或未改动时不重写文件。

写入前检查工作区、身份、路径和基线。新正文暂存并刷盘，Windows ReplaceFileW 在替换时保留旧正文。校验被替换的实际字节；发生竞争便保留备份与编辑稿并提示比较。外部变更、缺失身份及只读保护暂停自动保存。另存为仅在当前工作区排他创建并登记新 UUID。保存成功走已有索引协调流程。

每个窗口独立保存带版本和摘要的草稿，草稿记录身份、基线、编辑代次和原始格式。重启对照磁盘内容决定清理、恢复或比较；SQLite 可独立重建。恢复保证以已完成持久化的草稿为界。

预览使用 CommonMark、GFM 与数学节点，KaTeX 和字体随桌面程序离线提供。正文 HTML 作为文本展示，本地资源限制在已打开工作区。
