# 0006 工作区布局与链接索引

默认浅色，中央写作区采用实色，蓝灰侧栏和青绿色状态标识。宽屏按导航与文件、写作区、检查器约 18/63/19 分配空间。中等宽度收起检查器，窄窗允许使用文件抽屉。主题与侧栏变化仅调整样式，每份打开的文档保留独立 CodeMirror 会话。

背景 #F6F8FA，表面 #FFFFFF，次表面 #F1F5F6，强调色 #3B8278，边框 #DCE5E8。使用 4px 间距基准、8/12/16px 圆角，浮层渐变 160ms，系统减少动画时关闭。深色主题独立映射表面与文本颜色。字体按 Segoe UI、HarmonyOS Sans、微软雅黑、系统无衬线回退。数学使用本地 KaTeX 字体。

大纲反映未保存缓冲区；知识关系反映最近一次已提交的派生索引。源文档、Manifest v3 保持现有存储协议。代码和数学环境里的链接样例不进入反链。失效、同名歧义和缺少锚点分别诊断。
