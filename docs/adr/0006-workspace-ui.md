# 0006 工作区布局与链接索引

默认浅色，中央写作区采用实色，蓝灰侧栏和青绿色状态标识。宽屏按导航与文件、写作区、检查器约 18/63/19 分配空间。中等宽度收起检查器，窄窗允许使用文件抽屉。主题与侧栏变化仅调整样式，每份打开的文档保留独立 CodeMirror 会话。

背景 #F6F8FA，表面 #FFFFFF，次表面 #F1F5F6，强调色 #3B8278，边框 #DCE5E8。使用 4px 间距基准、8/12/16px 圆角，浮层渐变 160ms，系统减少动画时关闭。深色主题独立映射表面与文本颜色。字体按 Segoe UI、HarmonyOS Sans、微软雅黑、系统无衬线回退。数学使用本地 KaTeX 字体。

大纲反映未保存缓冲区；知识关系反映最近一次已提交的派生索引。源文档、Manifest v3 保持现有存储协议。代码和数学环境里的链接样例不进入反链。失效、同名歧义和缺少锚点分别诊断。

## 桌面实现决策

桌面将 core 的链接结果随文档索引写入 SQLite，并在同一事务更新派生 links 表。表以来源 Document ID 与链接序号为键，按目标 Document ID 建索引。旧 SQLite 记录缺少链接字段时仍可读取，下一次扫描重新解析正文。删除并重建 SQLite 可从源文件和 Manifest 恢复已解析关系。移动建议依赖上一份索引中的旧目标身份，重建时缺少该历史证据的链接继续报告缺失。

首轮修复只接受能在记录位置精确核对的普通行内 Markdown 链接。确认时复核目标路径，并通过现有保存入口校验源路径、身份与字节摘要。引用式链接、WikiLink 和不符合安全定位条件的目标保留诊断。源文件及 Manifest v3 无格式迁移。

实现与验证状态见 [desktop PR #5](https://github.com/Tsi-sheng/collations-desktop/pull/5)。
