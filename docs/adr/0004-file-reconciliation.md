# 0004 文件协调与 Manifest v3

v3 将 documents、generation、conflicts 和 history 置于同一事务。每个提案记录 UUID、目标相对路径、内容摘要、可用的文件身份及候选登记快照。pending、deferred、resolved、stale 分别表示待确认、暂缓、已处理及已失效。正文与附件不参与写入。

bind 仅接受仍缺失的候选；new 创建独立身份；defer 保留提案；undo 追加补偿记录，恢复旧登记。每项决策携带预期代次与提案 ID。文件或候选变化后须重新审阅。处理动作在工作区锁内重新扫描并比较预期清单。SQLite 保持可删除、可重建。

v1/v2 升级保留源清单备份。事务记录包含新旧清单及其 SHA-256。崩溃后依据校验过的版本恢复；证据不一致时只读报告并保全文件。全部身份元数据丢失后，单凭 Markdown 无法恢复旧 UUID。

监听仅收集脏路径。目录操作、溢出、恢复和周期校核触发完整扫描。内部元数据和重解析点不进入索引。
