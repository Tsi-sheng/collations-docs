# 产品范围与验收路线

更新2026-11-13。近期主线：版本历史与Markdown讲义闭环；高级布局先设计，Codex/Capture/AI后排。当前实现与验收以[HANDOFF](../HANDOFF.md)及[任务板](development/task-board.md)为准，版本号不是完成证明。

| 阶段 | 范围 | 当前状态/通过条件 |
|---|---|---|
| v0.1–v0.3 | 原生Markdown、身份协调、索引、编辑器、关系导航、单窗口定制与标签切换 | 功能分支已有实现及限定Windows验收，PR未合并；真人IME/物理DPI/安装/性能/Figma仍有缺口 |
| 收尾 | 同步当前基线、依赖、证据与遗留项 | 本批文档任务，不重跑已通过套件或清理旧树 |
| v0.4-A | 显式提交、不可变对象、版本清单、完整性及比较 | [协议接口审查](specs/history-v0.4.md)；实现未开始 |
| v0.4-B | 恢复前保全、单文档及附件安全恢复、独立历史视图 | 依赖A；中断和外部写入不可丢数据，SQLite删除不丢历史 |
| v0.4-C | Markdown作品、附件和来源映射 | 依赖固定版本读取；两讲义复用证明，冻结版本可重建 |
| v0.5 | 检索/局部图谱缺口、备份、干净环境与安装发布 | 先审计已有能力；离线完成搜索、跳转、恢复和导出 |
| 后续 | 高级布局、多标签组与独立窗口 | v0.4主线后单独评审单文档会话/单保存通道，未实现 |
| 独立小型验证 | 只读Codex接口 | 主线稳定后：搜索→按ID原文→反链→来源；公开样例、无写入，无需新仓/公网 |
| v0.6–v0.8 | 文献/页码引用/BibTeX与出版，再Capture，再Intelligence | 各自独立任务视图，保留来源及人工校对；未实施 |
| v0.9–v1.0 | macOS/Linux、同步、稳定API | 同协议样例和离线冲突恢复通过后开放，不作为Windows前置 |
| v1.x以后 | HarmonyOS阅读批注、授权分享与协作 | mobile/api/web保留职责；Mac Bridge等有Mac且需求验证后独立排期 |

下一实际任务只做收尾和v0.4协议接口审查；历史存储/恢复边界经审查后再写核心逻辑。现有Manifest v3、原始字节与安全写盘不能因新模块失效。UI保持轻量，版本/汇编/文献/采集不常驻写作区。

不预报日历日期；按交付关口估算。公开数学样例覆盖中文、公式、图片、块引用和两份讲义；真实文件/SQLite、故障注入、Windows打包与真人IME分别记录。旧路线里的Vitest/Playwright是工具规划，当前纯测以仓库实际Node测试命令为准，不为文档任务更换框架。
