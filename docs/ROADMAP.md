# 产品范围与验收路线

Windows v0.5 面向个人研究者，离线完成编辑、追溯和讲义汇编。协议与样例评审通过后按下表交付。

|版本|实现与验收|
|---|---|
|0.1|打包桌面壳，选择数学笔记目录，重建索引并比较源文件哈希。|
|0.2|编辑公式、预览配图、自动保存。在外部编辑和异常退出后找回双方内容。|
|0.3|建立块引用、反链及导入诊断。重命名定理后检查证明跳转和歧义报告。|
|0.4|提交、比较及恢复版本，生成两份共享证明的讲义。修改笔记后重新生成冻结版本并比对输出。|
|0.5|全文检索、局部图谱、备份恢复、Windows 安装包。在干净机器离线完成搜索、跳转、恢复和导出。|
|0.6–0.8|依次交付 PDF 页码引用与书籍出版、可校对并回溯原图的 OCR、带来源的研究问答。|
|0.9–1.0|验证 macOS/Linux 迁移和离线冲突恢复后开放同步，稳定 API 和插件接口。|
|1.x 以后|HarmonyOS 平板阅读与批注、可撤销分享、团队协作。|

Vitest 覆盖核心协议，临时工作区集成测试覆盖文件和 SQLite，Playwright 检查界面流程。安装包另测中文路径、权限、文件监听和强制退出。以 v0.1 实测打包和重建耗时作为后续估期依据。
